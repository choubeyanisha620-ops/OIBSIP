#  AI Desktop Voice Assistant

An advanced AI-powered desktop voice assistant built using Python.  
This project was developed as **Task 1** during my ongoing internship at **Oasis Infobyte**.

The assistant is capable of interacting with users through voice commands, performing system tasks, opening applications/websites, searching information, and providing a smooth conversational experience through a modern graphical interface.

---

#  Features

##  Voice Interaction
- Continuous voice listening
- Wake word detection ("Hey Assistant")
- Speech-to-text recognition
- Text-to-speech responses

##  Conversational Features
- Greetings and small talk
- Natural voice feedback
- Smart command handling

##  Web & Search
- Open Google, YouTube, Gmail
- Perform Google searches
- Wikipedia search integration

##  System Control
- Open desktop applications
- Close applications
- Volume control
- Shutdown & restart system (with confirmation)

##  File & Media
- Play music from local system
- Search files from Desktop/Documents

##  Modern GUI
- Built using Tkinter
- Dark-themed interface
- Real-time status updates
- Chat-style interaction panel

## 🧵 Advanced Functionality
- Multithreading for smooth UI performance
- Error handling
- Modular code structure
